HUD Pokémon

Cette extension se compose de 4 modules à installer séparément dans Owlbear Rodeo (Profil → Extensions → Add Extension), chacun avec sa propre URL de manifest ci-dessous :

🧑 Fiche Dresseur

Fiche du personnage + Pokédex.

manifest-fiche.json

🔴 Équipe

Les 6 Pokémon : invoquer, rappeler, relâcher, détails.

manifest-equipe.json

🎒 Sac & Dés

Inventaire (potions, baies, objets) + dés dirigés par le MJ.

manifest-inventaire.json

⚙️ Général (sans bulle)

PV sur tout token (clic droit) + mesure de distance en mètres.

manifest-general.json

Complétez chaque URL avec l'adresse de cette page. Voir le README du dépôt pour le détail des étapes.
